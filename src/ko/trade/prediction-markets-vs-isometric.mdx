# 예측 시장과 레버리지 거래 비교

가격 예측 시장은 예/아니오 질문을 던집니다. 다음 주 금요일에 비트코인이 $103,000보다 높을까? Isometric 거래도 한 시각의 가격 하나가 결과를 정한다는 점에서 처음에는 비슷해 보입니다. 차이는 지급액입니다. 예측 시장은 선을 넘었는지에 대해 지급합니다. Isometric은 가격이 그 선을 얼마나 넘었는지에 대해 지급합니다.

## 나란히 비교

|                       | 가격 예측 시장                                 | Isometric                                                 |
| --------------------- | ---------------------------------------------- | --------------------------------------------------------- |
| **고르는 것**         | 상장된 질문. 가격선과 날짜                     | 방향, 종료 시간, 금액, 레버리지                           |
| **지급액**            | 전부 아니면 전무. 맞히면 지분당 고정 금액      | 가치 소멸 가격을 1% 넘을 때마다 늘어나며, 최대 지급액까지 |
| **아슬아슬한 빗나감** | 지급 없음                                      | 지불한 금액의 일부를 돌려받을 수 있음                     |
| **최대 손실**         | 지불한 금액                                    | 지불한 금액                                               |
| **지불하는 가격**     | 다른 트레이더가 정하며, 오더북 깊이만큼만 체결 | 매도자가 전체 규모에 대해 한 번에 견적                    |
| **중도 종료**         | 보통 언제든 가능. 다른 트레이더에게 매도       | 정산 시에만                                               |
| **날짜**              | 누군가 상장한 날짜                             | 12시간~7일 기간                                           |
| **결과 결정**         | 마켓 자체의 결과 판정 규칙                     | 정산 시각의 Chainlink 가격                                |

## 같은 관점, 두 가지 방법

비트코인이 $100,000이고, 3일 뒤 더 높을 것이라고 생각합니다. 가진 돈은 $100입니다.

- **예측 시장.** "3일 뒤 $103,000 이상?"에 예를 삽니다. 예가 30센트에 거래되고 맞히면 $1를 지급한다고 가정하면, $100로 약 333지분을 삽니다.
- **Isometric.** [차트 읽기](./reading-the-chart.mdx)의 3일, 25x 롱을 엽니다. 가치 소멸 가격 $97,400, 손익분기점 $101,296, 최대 지급액 $323입니다.

| 정산 시 비트코인 가격 | 예측 시장 지급액 | Isometric 지급액 |
| --------------------- | ---------------- | ---------------- |
| $99,000               | $0               | $41              |
| $102,000              | $0               | $118             |
| $105,000              | $333             | $195             |
| $107,000              | $333             | $246             |
| $112,000              | $333             | $323             |

선을 겨우 넘는 움직임에는 예측 시장이 더 많이 지급합니다. Isometric은 아슬아슬하게 빗나가도 일부를 돌려주고, 움직임이 커질수록 최대치까지 계속 더 지급합니다. 예시 수치이며, 양쪽 모두 실제 가격은 시장에 따라 움직입니다.

## Isometric이 더 잘 맞는 경우

- **특정 선이 아니라 방향에 대한 관점이 있을 때.** 원하는 가격과 날짜에 맞는 상장된 질문을 찾을 필요가 없습니다. 롱이나 숏, 그리고 종료 시간을 고르면 차트가 모든 가격의 지급액을 보여 줍니다.
- **움직임의 크기만큼 지급받고 싶을 때.** 큰 움직임은 작은 움직임보다 더 많이 지급합니다.
- **아슬아슬한 빗나감도 인정받고 싶을 때.** **Some back** (일부 회수) 구간에서는 돈의 일부를 돌려받습니다.
- **전체 규모에 하나의 가격을 원할 때.** 매도자가 전체 금액에 대해 견적을 냅니다. 오더북을 훑어 내려갈 필요가 없습니다.

## 예측 시장이 더 잘 맞는 경우

- **정확히 한 선에 대한 관점이 있을 때.** 가격이 $103,000를 넘는지만 중요하다면, 예/아니오 지분이 그것을 정확히 표현합니다.
- **중도에 빠져나오고 싶을 때.** 보통 결과 판정 전에 지분을 팔 수 있습니다. Isometric 포지션은 정산까지 유지됩니다.
- **가격이 아닌 다른 것을 거래하고 싶을 때.** Isometric은 시장 가격만 거래합니다.
