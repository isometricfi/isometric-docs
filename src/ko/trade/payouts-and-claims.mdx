# 지급과 수령

롱이든 숏이든 모든 지급액은 **USDG**로 지급되며, USDC나 USDT로 결제했더라도 마찬가지입니다. 다른 토큰이나 네트워크로 옮기려면 [스왑](./pay-and-swap.mdx)을 이용하세요.

## 포지션이 지급될 때

지급은 자동으로 이루어집니다. 종료 가격을 기록하는 트랜잭션에서 지급액이 지갑으로 함께 전송되며, 보통 종료 시간 후 1~2분 안에 처리됩니다. 그러면 포지션이 **지급 완료**로 표시됩니다.

## 직접 수령해야 할 때

지갑이 USDG 수신을 차단당한 경우처럼 지갑으로의 전송이 실패하면, 포지션은 대신 **수익 확정**으로 표시됩니다. 잃은 것은 없습니다. 지급액은 컨트랙트에서 기다리며 기한이 없습니다.

**포트폴리오**를 열고 포지션을 선택한 뒤 **수령**을 누르세요. **내 지갑** 또는 **다른 주소**로 보낼 수 있습니다.

<Warning>
  지급액 전부가 입력한 주소로 전송되며 되돌릴 수 없습니다. 모든 글자를 확인하고, 해당 주소가
  Arbitrum One에서 USDG를 받을 수 있는지 확인하세요.
</Warning>

## 포지션 상태

| 상태      | 의미                                                                                       |
| --------- | ------------------------------------------------------------------------------------------ |
| 보유 중   | 종료 시간이 아직 오지 않았습니다                                                           |
| 종료 중   | 종료 시간이 지났고, 종료 가격이 기록되기를 기다리고 있습니다                               |
| 지급 완료 | 종료되어 지갑으로 지급되었습니다                                                           |
| 수익 확정 | 지급액이 있는 상태로 종료되었지만 전송이 실패했습니다. 수령하세요                          |
| 손실      | 범위 밖에서 종료되어 지급액이 없습니다                                                     |
| 환불됨    | 종료 시간 후 14일 안에 종료 가격이 없어, 지불한 금액에서 수수료를 뺀 금액이 반환되었습니다 |

## 포트폴리오에 표시되는 내용

| 항목                          | 의미                                                             |
| ----------------------------- | ---------------------------------------------------------------- |
| 지금 종료 시 보유 포지션 가치 | 보유 중인 포지션이 현재 가격에서 지급할 금액입니다. 참고용입니다 |
| 보유 포지션 최대 지급액       | 보유 중인 포지션이 지급할 수 있는 최대 금액입니다                |
| 수령 가능                     | 수령을 기다리는 지급액입니다                                     |
| 승률                          | 종료된 포지션 중 비용보다 많이 지급된 포지션의 비율입니다        |
| 총 지불액 (수수료 포함)       | 포지션에 지불한 금액 전체입니다                                  |
| 총 지급액                     | 지금까지 지급받은 금액 전체입니다                                |
| 실현 손익                     | 종료된 포지션의 총 지급액에서 총 지불액을 뺀 값입니다            |

각 행은 해당 트랜잭션으로 연결되므로, 모든 단계를 온체인에서 확인할 수 있습니다.
