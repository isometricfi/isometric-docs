# 여기서 레버리지의 의미

무기한 선물에서 레버리지는 얼마나 빌리는지를 뜻하며, 포지션이 청산되는 가격이 함께 따라옵니다. Isometric에는 차입도 청산도 없습니다. 레버리지는 두 가지를 정합니다. 포지션의 크기, 그리고 차트에서 **Lose** (손실) 선이 놓이는 위치입니다.

주문 창의 **레버리지**에서 고르세요. 5x, 10x, 15x, 20x, 25x, 30x, 40x, 50x, 75x, 100x 중에서 선택할 수 있습니다.

## 레버리지는 포지션 규모를 정합니다

포지션 규모는 투입 금액에 레버리지를 곱한 값이며, 거래당 **5,000 USDG**가 한도입니다. 레버리지가 높을수록 넣을 수 있는 최대 금액이 줄어들며, 주문 창에 **최대**로 표시됩니다.

| 레버리지 | 최대 투입 금액 |
| -------- | -------------- |
| 5x       | $1,000         |
| 10x      | $500           |
| 25x      | $200           |
| 50x      | $100           |
| 100x     | $50            |

최소 금액은 $1입니다.

## 레버리지는 손실선을 움직입니다

같은 포지션에 덜 지불한다는 것은 위험이 더 크다는 뜻입니다. 레버리지가 높을수록 가치 소멸 가격이 현재 가격에 가까워지고, 약 50x부터는 현재 가격을 넘어섭니다. 그만큼 조금만 어긋나도 전부 잃게 됩니다.

비트코인이 $100,000일 때 포지션 규모가 각각 $5,000인 3일짜리 비트코인 롱 다섯 개입니다.

| 레버리지 | 투입 금액 | 가치 소멸 가격 | 손익분기점 | 최대 지급액 |
| -------- | --------- | -------------- | ---------- | ----------- |
| 5x       | $1,000    | $83,738        | $100,486   | $1,568      |
| 10x      | $500      | $91,402        | $100,542   | $1,017      |
| 25x      | $200      | $97,388        | $101,283   | $648        |
| 50x      | $100      | $100,466       | $102,476   | $474        |
| 100x     | $50       | $102,936       | $103,965   | $343        |

예시 수치입니다. 실제 수치는 차트에 표시됩니다.

- **낮은 레버리지**는 가격에 대한 안전하고 작은 베팅입니다. 전부 잃는 일도 드물고, 몇 배로 지급되는 일도 드뭅니다.
- **높은 레버리지**는 유리한 방향으로 조금만 움직여도 크게 지급하고, 불리한 방향으로 조금만 움직여도 전부 잃습니다.

**가치 소멸 가격을 1% 넘을 때마다 투입 금액에서 레버리지 수치와 같은 비율(%)이 지급되며**, 최대치까지 늘어납니다. 25x에서는 1%마다 투입 금액의 25%입니다. 시장이 잠잠할 때는 선들이 현재 가격에 더 가깝게 놓입니다. 변동성이 클 때는 매도자가 더 큰 움직임을 가격에 반영하므로 더 멀리 놓입니다.

## 청산가 없음

포지션이 열려 있는 동안에는 아무 일도 일어나지 않습니다. 25x 롱이 첫날 10% 불리하게 움직였다가 둘째 날 회복하면, 셋째 날 전액 지급됩니다. 같은 레버리지의 무기한 선물이라면 첫날 청산되었을 것입니다.

## 레버리지 고르기

얼마를 벌고 싶은지가 아니라, 종료 시간에 가격이 어디에 있을지를 생각하세요.

- 가격이 내 방향으로 천천히 움직이거나 유지될 것 같으면 낮은 레버리지를 고르세요.
- 가격이 확실하게 움직일 것 같으면 높은 레버리지를 고르세요.

결정하기 전에 레버리지를 바꿔 보며 차트의 구간이 어떻게 움직이는지 확인하세요.
