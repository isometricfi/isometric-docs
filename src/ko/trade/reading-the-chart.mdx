# 차트 읽기

차트가 곧 주문 창입니다. 왼쪽에는 최근 2일간의 가격이 있습니다. 오른쪽, **종료**로 표시된 선 너머에는 가능한 모든 종료 가격에서 거래가 얼마를 지급하는지 보여 주는 구간이 있습니다. 그 선에서의 가격만 반영됩니다. 도중에 가격이 빠져도 결과에는 영향이 없습니다.

## 구간

롱 기준, 위에서 아래 순서입니다.

| 구간                      | 의미                                                                                  |
| ------------------------- | ------------------------------------------------------------------------------------- |
| **Max** (최대)            | 최상단 가격에 닿거나 넘으면 지급액이 더 늘지 않습니다. 라벨에 최대 수익이 표시됩니다. |
| 초록색                    | 중간 가격과 최상단 가격 사이에서는 투입 금액보다 많이 돌려받습니다.                   |
| **Some back** (일부 회수) | 최하단 가격과 중간 가격 사이에서는 투입 금액의 일부를 돌려받습니다.                   |
| **Lose** (손실)           | 최하단 가격 이하에서는 아무것도 지급되지 않습니다. 라벨에 손실 금액이 표시됩니다.     |

숏은 같은 차트를 위아래로 뒤집은 모양입니다. **Max** 구간이 아래에, **Lose**가 위에 있습니다.

오른쪽 끝의 세 가격은 **가치 소멸 가격**(빨간색), **손익분기점**(초록색), **상한가**(**Max**가 시작되는 가격)입니다. 구간 안 아무 곳에나 마우스를 올리거나 탭하면 해당 종료 가격과 정확한 지급액을 볼 수 있습니다.

## 구간을 움직이는 요소

- **레버리지.** 레버리지가 높을수록 **Lose** 선이 현재 가격에 가까워져, 더 작은 역방향 움직임에도 전부 잃습니다. 가치 소멸 가격을 1% 넘을 때마다 지급액도 더 커집니다. [레버리지](./leverage.mdx)를 참고하세요.
- **종료선.** 종료 시간이 늦을수록 손익분기점이 조금 더 멀어지고 **Max** 구간도 더 멀어져, 최대 지급액이 커집니다.
- **투입 금액.** 금액이 클수록 모든 지급액이 비례해 커집니다. 가격은 그대로입니다.

## 예시

비트코인이 **$100,000**입니다. **롱**을 선택하고 **25x**로 **$100**를 넣은 뒤, 종료선을 **3일**로 드래그합니다. 차트는 다음과 같이 표시될 수 있습니다.

| 차트의 가격    | 값                           |
| -------------- | ---------------------------- |
| 상한가         | $110,000, 라벨 **Max +$223** |
| 손익분기점     | $101,296                     |
| 가치 소멸 가격 | $97,400, 라벨 **Lose $100**  |

종료 가격별 지급액:

| 종료 시 비트코인 가격 | 수령액 | 결과  |
| --------------------- | ------ | ----- |
| $97,400 이하          | $0     | −$100 |
| $100,000              | $67    | −$33  |
| $101,296              | $100   | $0    |
| $104,000              | $169   | +$69  |
| $107,000              | $246   | +$146 |
| $110,000 이상         | $323   | +$223 |

25x에서는 가치 소멸 가격을 1% 넘을 때마다 투입 금액의 약 25%, 이 예시에서는 약 $25의 가치가 있습니다. $110,000를 넘으면 지급액이 더 늘지 않습니다. 비트코인이 $150,000여도 똑같이 $323가 지급됩니다.

예시 수치입니다. 실제 수치는 실시간 가격과 매도자가 보내는 견적에 따라 달라집니다.

## 견적은 시장을 따라갑니다

가격이 움직이면 구간도 갱신됩니다. 각 견적은 짧은 시간 동안 확정 유효하며, 서명하기 전에 앱이 견적을 새로 고칩니다. 거래는 내가 확인한 견적 그대로 열리거나, 아예 열리지 않습니다. 실패한 거래의 비용은 네트워크 수수료뿐입니다.
