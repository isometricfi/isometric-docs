# 작동 원리

모든 Isometric 포지션은 옵션 스프레드입니다.

- **롱은 콜 스프레드입니다.** 가격이 가치 소멸 가격 위로 오를수록 지급하며, 상한가까지 늘어납니다.
- **숏은 풋 스프레드입니다.** 가격이 가치 소멸 가격 아래로 내릴수록 지급하며, 하한가까지 늘어납니다.
- **스프레드는 내가 사고, 매도자가 팝니다.** 매도자들이 내 거래에 경쟁적으로 견적을 내고, 가장 좋은 견적으로 체결됩니다.
- **완전 담보됩니다.** 거래가 열릴 때 내 프리미엄과 매도자의 예치금이 **최대 지급액** 전체를 보장합니다.
- **종료 시간에 한 번 정산됩니다.** Chainlink 가격 하나가 지급액을 정하며, USDG로 지급됩니다. 조기 행사도, 중도 종료도 없습니다.

## 옵션 용어로 본 차트

| 차트에서             | 옵션 용어                                 |
| -------------------- | ----------------------------------------- |
| **Lose** (손실) 선   | 행사가                                    |
| **Max** (최대) 선    | 상한가, 숏이라면 하한가                   |
| 최대 지급액          | 행사가와 상한가 사이 스프레드의 전체 가치 |
| 투입 금액            | 프리미엄과 거래 수수료의 합               |
| 투입 금액 × 레버리지 | 명목 금액                                 |
| **종료**             | 만기                                      |

레버리지는 명목 금액을 지불한 금액으로 나눈 값입니다. 증거금 요건이 아니라 스프레드의 크기를 정하므로, 청산할 대상이 없습니다.
