# 용어집

| 용어                             | 의미                                                                                                                                     |
| -------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------- |
| 금액 (Amount)                    | **You put in** (투입 금액)에 입력하는 값으로, USDG 기준입니다. 레버리지와 함께 포지션 규모를 정하며, 수수료를 포함해 지불하는 전부입니다 |
| Arbitrum                         | Isometric이 운영되는 이더리움 레이어 2 네트워크입니다. Arbitrum One이 메인 네트워크, Arbitrum Sepolia가 테스트넷입니다                   |
| 베타 (Beta)                      | Arbitrum One에서 진행 중인 Isometric의 현재 출시 단계로, 컨트랙트는 감사를 받지 않았고 포지션 규모에 한도가 있습니다                     |
| 손익분기점 (Breakeven)           | 포지션이 비용과 정확히 같은 금액을 돌려주는 종료 가격입니다. 차트의 초록색 가격입니다                                                    |
| Chainlink                        | 가격 피드로 모든 견적의 출발점이 되고, 종료 시간에 모든 포지션의 결과를 결정하는 오라클 네트워크입니다                                   |
| 수령 (Claim)                     | 지갑으로의 전송이 실패한 지급액을 받아 가는 것입니다. 어떤 주소로든 보낼 수 있습니다                                                     |
| 담보 (Collateral)                | 포지션이 열릴 때 매도자가 예치하는 금액으로, **최대 지급액**에서 트레이더의 프리미엄을 뺀 값입니다                                       |
| 계약 수 (Contracts)              | 마켓 기초 자산 단위로 나타낸 포지션 크기입니다                                                                                           |
| 데모 모드 (Demo mode)            | 모의 자금으로 앱을 실행하는 모드입니다. 지갑, 가스, 체인이 필요 없습니다                                                                 |
| 방향 (Direction)                 | 롱 또는 숏입니다                                                                                                                         |
| 종료 시간 (End time)             | 거래나 예측이 끝나는 날짜와 시각으로, **종료**로 표시됩니다. 그 시점의 Chainlink 가격 하나가 결과를 결정합니다                           |
| 종료 중 (Ending)                 | 종료 시간이 지났지만 아직 종료 가격이 기록되지 않은 포지션입니다                                                                         |
| 키퍼 (Keeper)                    | 종료 시간 이후 종료 가격을 기록하고 포지션에 지급하는 작업자입니다. 누구나 같은 일을 할 수 있습니다                                      |
| 레버리지 (Leverage)              | 포지션 규모를 투입 금액으로 나눈 값으로, 5x~100x입니다. 규모를 정하고 손실선 위치를 정합니다. 청산가는 생기지 않습니다                   |
| 롱 (Long)                        | 종료 가격이 가치 소멸 가격보다 높으면 지급되는 포지션입니다                                                                              |
| 손실 (Lost)                      | 아무것도 지급하지 않고 종료된 포지션입니다                                                                                               |
| 최대 지급액 (Max payout)         | 포지션이 지급할 수 있는 최대 금액으로, 오픈 시 확정됩니다. 차트의 **Max** (최대) 라벨은 이를 수익으로 표시합니다                         |
| 지급 완료 (Paid)                 | 지급액이 지갑에 도착한 종료 포지션입니다                                                                                                 |
| 지급액 (Payout)                  | 가격이 목표가에 닿거나 넘어서 끝났을 때 예측이 지급하는 금액으로, **If you're right** (적중 시)로 표시됩니다                             |
| 포지션 규모 (Position size)      | 투입 금액에 레버리지를 곱한 값입니다. 노출 규모이며, 현재 거래당 5,000 USDG가 한도입니다                                                 |
| 예측 (Prediction)                | 종료 시간에 가격이 목표가보다 위 또는 아래에서 끝날지에 거는 것입니다                                                                    |
| 프리미엄 (Premium)               | 트레이더가 포지션 대가로 매도자에게 지불하는 금액으로, 투입 금액에서 거래 수수료를 뺀 값입니다                                           |
| 견적 (Quote)                     | 매도자가 거래에 대해 서명한 가격입니다. 가장 좋은 견적으로 체결됩니다                                                                    |
| 환불됨 (Refunded)                | 종료 시간 후 14일 안에 종료 가격이 없었던 포지션입니다. 양쪽 모두 수수료를 뺀 금액을 돌려받았습니다                                      |
| 숏 (Short)                       | 종료 가격이 가치 소멸 가격보다 낮으면 지급되는 포지션입니다                                                                              |
| 행사가 (Strike)                  | 가치 소멸 가격을 가리키는 옵션 용어입니다                                                                                                |
| 목표가 (Target)                  | 예측이 전액 지급되려면 가격이 닿거나 넘어서 끝나야 하는 가격입니다                                                                       |
| 스왑 (Swap)                      | Arbitrum 안에서 또는 네트워크 사이에서 토큰을 다른 토큰으로 바꾸는 것입니다. USDC와 USDT로 거래를 결제하면 USDG로 스왑됩니다             |
| 기간 (Term)                      | 포지션이 유지되는 기간으로, 12시간~7일입니다                                                                                             |
| USDG                             | 글로벌 달러(Global Dollar). 포지션이 정산되고, 지급액이 지급되며, 매도자가 예치하는 달러 스테이블코인입니다                              |
| 수익 확정 (Won)                  | 지급액이 있지만 전송이 실패한 종료 포지션입니다. 수령하세요                                                                              |
| 가치 소멸 가격 (Worthless price) | 종료 가격이 이 가격에 닿거나 넘어서면 포지션이 아무것도 지급하지 않습니다. 차트의 빨간색 **Lose** (손실) 선입니다                        |
| 매도자 (Writer)                  | 견적을 내서 예측과 거래의 반대편을 맡는 사람입니다                                                                                       |
