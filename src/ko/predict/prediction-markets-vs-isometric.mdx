# 예측 시장과 Isometric 비교

Polymarket 같은 상장형 예측 시장은 다른 사람이 만든 질문을 제공합니다. 금요일에 비트코인이 $105,000보다 높을까? 목록에 있는 가격과 날짜 중에서 고르게 됩니다. Isometric에서는 질문을 직접 만듭니다.

## 나란히 비교

|               | 상장형 예측 시장                 | Isometric                              |
| ------------- | -------------------------------- | -------------------------------------- |
| **가격**      | 정해진 몇 개의 가격대            | 매도자가 견적하는 모든 가격            |
| **종료 시간** | 정해진 날짜                      | 12시간~7일, 1시간 단위 기간            |
| **체결**      | 오더북 깊이만큼                  | 매도자가 전체 금액에 대해 한 번에 견적 |
| **지급액**    | 지분당 고정                      | 예측 시점에 확정                       |
| **최대 손실** | 지불한 금액                      | 지불한 금액                            |
| **중도 종료** | 보통 언제든 가능. 보유 지분 매도 | 종료 시간까지 유지                     |
| **결과 결정** | 마켓 자체의 결과 판정 규칙       | 종료 시간의 온체인 Chainlink 가격 하나 |

## Isometric이 더 잘 맞는 경우

- **나만의 선에 대한 관점이 있을 때.** 화요일 18:00까지 BTC $103,500 이상처럼, 아무도 상장하지 않은 예측도 할 수 있습니다.
- **전체 금액에 하나의 가격을 원할 때.** 오더북을 훑어 내려갈 필요가 없습니다.
- **명확한 결과를 원할 때.** 온체인 가격 하나로 정산되며, 이의 제기나 투표가 없습니다.

## 상장형 마켓이 더 잘 맞는 경우

- **중도에 빠져나오고 싶을 때.** 보통 종료 전에 지분을 팔 수 있습니다. Isometric 예측은 종료 시간까지 유지됩니다.
- **가격이 아닌 다른 것에 걸고 싶을 때.** Isometric은 시장 가격만 예측합니다.
