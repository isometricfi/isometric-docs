# Markets

  or USDT, which is swapped to USDG as the trade opens. You never receive the market's own asset.
</Note>

## What is on offer

| Setting  | Options                                                           |
| -------- | ----------------------------------------------------------------- |
| Terms    | 1, 2, and 3 days, or a custom term from 24 to 72 hours            |
| Leverage | 5x, 10x, 15x, 20x, 25x, 30x, 40x, 50x, 75x, 100x, and 1000x       |
| Amount   | From $1, up to a position size of 5,000 USDG                      |
| Pay with | USDG, USDC, or USDT. See [Pay and swap](./trade/pay-and-swap.mdx) |
| Payouts  | USDG                                                              |
| Network  | Arbitrum One. The testnet runs on Arbitrum Sepolia                |

## Who takes the other side

Every trade goes out for quotes. Writers answer with a price, and the best one fills. Each writer puts up the full **Max payout** for the trades it fills, so every market draws on the same writers.

## Prices

The chart and the header ticker read the exchange price, which is Coinbase for crypto. Trades are never priced from the chart. Each quote starts from the **Chainlink** price on chain at the moment you ask, and the position settles from the same feed at expiry.
