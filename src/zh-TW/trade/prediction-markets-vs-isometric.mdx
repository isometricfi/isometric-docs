# 預測市場與槓桿交易比較

價格預測市場問的是一道是非題：Bitcoin 下週五會高於 $103,000 嗎？Isometric 交易乍看之下很像，因為都是由某個時間的一個價格決定結果。差別在於賠付方式。預測市場只看價格有沒有越過那條線，Isometric 則看價格越過那條線多遠。

## 並列比較

|                | 價格預測市場                         | Isometric                                    |
| -------------- | ------------------------------------ | -------------------------------------------- |
| **你選擇什麼** | 一道上架的題目：一條價格線和一個日期 | 方向、結束時間、金額和槓桿                   |
| **賠付**       | 全有或全無：猜對時每份額賠付固定金額 | 越過歸零價後每多 1% 賠付就增加，直到最高賠付 |
| **差一點命中** | 無賠付                               | 可以拿回部分支付金額                         |
| **最大虧損**   | 你支付的金額                         | 你支付的金額                                 |
| **你付的價格** | 由其他交易者決定，深度取決於訂單簿   | 由賣方報價，一次涵蓋全部規模                 |
| **出場**       | 通常可隨時賣給其他交易者             | 僅在結算時                                   |
| **日期**       | 別人上架的日期                       | 12 小時至 7 天的天期                         |
| **由什麼決定** | 該市場自己的判定規則                 | 結算整點的 Chainlink 價格                    |

## 同一個看法，兩種做法

Bitcoin 目前價格為 $100,000，你認為三天後會更高。你有 $100。

- **預測市場。** 你在「3 天後高於 $103,000？」買入「是」。假設「是」的價格為 30 美分，猜對時賠付 $1。$100 約可買到 333 份。
- **Isometric。** 你開立[解讀圖表](./reading-the-chart.mdx)中那筆 3 天期、25x 的多單：歸零價 $97,400，損益兩平價 $101,296，最高賠付 $323。

| 結算時的 Bitcoin | 預測市場賠付 | Isometric 賠付 |
| ---------------- | ------------ | -------------- |
| $99,000          | $0           | $41            |
| $102,000         | $0           | $118           |
| $105,000         | $333         | $195           |
| $107,000         | $333         | $246           |
| $112,000         | $333         | $323           |

如果價格只是剛好越過那條線，預測市場賠得比較多。Isometric 在差一點命中時能讓你拿回一些錢，而且隨著行情擴大持續增加賠付，直到上限。以上為範例數字：兩邊的實際價格都會隨市場變動。

## Isometric 更適合的情況

- **你有方向，而不是一條特定的線。** 你不需要找到價格和日期剛好合適的上架題目。選擇做多或做空和結束時間，圖表就會顯示每個價格的賠付。
- **你希望依行情大小獲得賠付。** 大行情賠得比小行情多。
- **你希望差一點命中也算數。** 在 **Some back**（拿回部分）色帶中，你可以拿回部分資金。
- **你希望整筆規模同一個價格。** 賣方為全部金額報價，沒有需要逐檔吃單的訂單簿。

## 預測市場更適合的情況

- **你只看好某一條特定的線。** 如果你只在乎價格會不會越過 $103,000，是非題份額正好表達這一點。
- **你想提前出場。** 通常可以在判定前賣出你的份額。Isometric 部位會持有到結算。
- **你想交易價格以外的東西。** Isometric 只交易市場價格。
