# 運作方式

每個 Isometric 部位都是一個選擇權價差。

- **做多是買權價差。** 價格漲過你的歸零價後開始賠付，直到上限為止。
- **做空是賣權價差。** 價格跌破你的歸零價後開始賠付，直到下限為止。
- **你買入價差，賣方賣出價差。** 賣方競相為你的交易報價，由最優報價成交。
- **足額擔保。** 交易開立時，你的權利金和賣方的存入資金就足以支付你全部的**最高賠付**。
- **只在結束時間結算一次。** 一個 Chainlink 價格決定賠付，以 USDG 支付。不能提前履約，也不能提前平倉。

## 用選擇權術語看圖表

| 圖表上          | 選擇權術語                             |
| --------------- | -------------------------------------- |
| **Lose** 線     | 履約價                                 |
| **Max** 線      | 上限價（做空時為下限價）               |
| 最高賠付        | 價差的完整價值，介於履約價與上限價之間 |
| 投入金額        | 權利金加上交易手續費                   |
| 投入金額 × 槓桿 | 名目本金                               |
| **結束**        | 到期日                                 |

槓桿是名目本金除以你支付的金額。它決定價差的規模，而不是保證金要求，所以沒有東西可以被強平。
