# 手續費

一個部位只需付款一次，在開倉時支付。你的投入金額就是你支付的全部費用（含手續費）。

## 交易手續費

手續費為 **$0.50 加上部位規模的 0.06%**，且不超過投入金額的 5%。手續費從投入金額中扣除，不會另外加收。

## 你永遠不用付的費用

| 永續合約         | Isometric          |
| ---------------- | ------------------ |
| 每小時的資金費率 | 無                 |
| 平倉手續費       | 無。沒有平倉這回事 |
| 強平罰金         | 無。沒有強平這回事 |
| 賠付的提領手續費 | 無                 |
| 獲利抽成         | 無                 |

## 網路手續費

用 USDG 開倉只需在 Arbitrum 上送出一筆交易，以你錢包中的 ETH 支付。任何授權要嘛是免費簽名，要嘛和交易一起送出。

結算由 Isometric 的 keeper 送出，網路手續費由它自行支付，賠付則直接進入錢包。只有在你需要自己[領取](./payouts-and-claims.mdx)賠付時，才需要在結算後支付網路手續費。

## 兌換成本

Isometric 不收取任何兌換手續費，包括你用 USDC 或 USDT 支付交易時。匯率來自負責兌換路由的第三方。如果你的錢包不支援批次交易，用 USDC 或 USDT 支付還需要負擔授權和兌換的網路手續費。請參閱[支付與兌換](./pay-and-swap.mdx)。

## 手續費會變動嗎

手續費可以在合約程式碼設定的限制內調整。調整只適用於之後開立的部位，絕不影響已開立的部位。
