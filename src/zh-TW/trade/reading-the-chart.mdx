# 解讀圖表

圖表就是你的下單介面。左側是過去兩天的價格。右側越過標示**結束**的線之後，是一條條色帶，顯示你的交易在每個可能結束價下的賠付。只有那條線上的價格才算數，途中的下跌不會決定任何事。

## 色帶

以做多為例，由上到下：

| 色帶                      | 意義                                                               |
| ------------------------- | ------------------------------------------------------------------ |
| **Max**（最高）           | 價格達到或越過最上方的價格後，賠付不再增加。標籤顯示你的最高獲利。 |
| 綠色                      | 介於中間價格與最上方價格之間，你拿回的金額會超過投入金額。         |
| **Some back**（拿回部分） | 介於最下方價格與中間價格之間，你可以拿回部分投入金額。             |
| **Lose**（虧損）          | 價格等於或低於最下方的價格時，交易無賠付。標籤顯示你會損失的金額。 |

做空的圖表則是上下顛倒：**Max** 色帶在底部，**Lose** 在頂部。

右側邊緣的三個價格分別是**歸零價**（紅色）、**損益兩平價**（綠色）和**上限價**（**Max** 的起點）。將游標移到或點按色帶中的任一位置，即可看到該結束價及其確切賠付。

## 什麼會移動色帶

- **槓桿。** 槓桿越高，**Lose** 線越靠近目前價格，價格只要小幅朝不利方向變動就會全部虧光。越過歸零價後，每 1% 的賠付也越多。請參閱[槓桿](./leverage.mdx)。
- **結束線。** 結束時間越晚，損益兩平價會稍微遠離，**Max** 色帶也會更遠，因此最高賠付會增加。
- **你的金額。** 金額越大，每個賠付都等比例放大，價格則維持不變。

## 完整範例

Bitcoin 目前價格為 **$100,000**。你選擇**做多**，以 **25x** 投入 **$100**，並將結束線拖到 **3 天**。圖表可能顯示：

| 圖表上的價格 | 數值                           |
| ------------ | ------------------------------ |
| 上限價       | $110,000，標示為 **Max +$223** |
| 損益兩平價   | $101,296                       |
| 歸零價       | $97,400，標示為 **Lose $100**  |

每個結束價的賠付：

| 結束時的 Bitcoin | 你收到 | 結果  |
| ---------------- | ------ | ----- |
| $97,400 或以下   | $0     | −$100 |
| $100,000         | $67    | −$33  |
| $101,296         | $100   | $0    |
| $104,000         | $169   | +$69  |
| $107,000         | $246   | +$146 |
| $110,000 或以上  | $323   | +$223 |

在 25x 槓桿下，越過歸零價後每 1% 約等於投入金額的 25%，此例中約為 $25。超過 $110,000 後賠付不再增加：Bitcoin 即使漲到 $150,000，賠付仍是同樣的 $323。

以上為範例數字。你的實際數字取決於即時價格和賣方的報價。

## 報價跟隨市場

色帶會隨價格變動更新。每筆報價只在短時間內有效，App 會在你簽署前更新報價。你的交易會完全依照你確認的報價開立，否則就不會開立。失敗的交易只需支付網路手續費。
