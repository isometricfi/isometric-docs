# 賠付與領取

不論做多或做空，每筆賠付都以 **USDG** 支付，即使你是用 USDC 或 USDT 付款。若要換成其他代幣或轉到其他網路，請使用[兌換](./pay-and-swap.mdx)。

## 部位何時賠付

賠付會自動發放。賠付會在記錄結束價的同一筆交易中轉入你的錢包，通常在結束時間後一兩分鐘內。之後部位會顯示**已賠付**。

## 何時需要領取

如果轉入你錢包的轉帳失敗，例如錢包被禁止接收 USDG，部位會改為顯示**獲利**。你不會損失任何東西。賠付會留在合約中，永不過期。

打開**投資組合**，選擇該部位，然後按**領取**。可以發送到**我的錢包**或**其他地址**。

<Warning>
  全部賠付將發送至你輸入的地址，且無法退回。請逐字核對，並確認該地址可在 Arbitrum One 上接收 USDG。
</Warning>

## 部位狀態

| 狀態   | 意義                                                         |
| ------ | ------------------------------------------------------------ |
| 持有中 | 尚未到結束時間                                               |
| 結束中 | 已過結束時間，正在等待記錄結束價                             |
| 已賠付 | 已結束並賠付至你的錢包                                       |
| 獲利   | 已結束並產生賠付，但轉帳失敗。請領取                         |
| 虧損   | 結束價落在區間之外，因此無賠付                               |
| 已退款 | 結束時間後 14 天內沒有結束價，你支付的金額已扣除手續費後退還 |

## 投資組合顯示的資訊

| 數據                     | 意義                                               |
| ------------------------ | -------------------------------------------------- |
| 持有部位若立即結束的價值 | 你持有中的部位以目前價格計算可獲得的賠付，僅供參考 |
| 持有部位最高賠付         | 你持有中的部位最多可獲得的賠付                     |
| 可領取                   | 等待你領取的賠付                                   |
| 勝率                     | 已結束部位中，賠付超過成本的比例                   |
| 總投入（含手續費）       | 你為部位支付的全部金額                             |
| 總賠付                   | 你已收到的全部賠付                                 |
| 已實現損益               | 已結束部位的總賠付減去總投入                       |

每一列都連結到對應的交易，所以每個步驟都可以在鏈上查證。
