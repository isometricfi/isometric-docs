# 這裡的槓桿是什麼意思

在永續合約上，槓桿代表你借了多少錢，並伴隨一個讓你爆倉的價格。在 Isometric 上沒有借貸，也沒有強平。槓桿只做兩件事：決定你的部位有多大，以及 **Lose** 線在圖表上的位置。

在下單介面的**槓桿**中選擇：5x、10x、15x、20x、25x、30x、40x、50x、75x 或 100x。

## 槓桿決定部位規模

部位規模是投入金額乘以槓桿，每筆交易上限為 **5,000 USDG**。槓桿越高，可投入的最高金額越低，下單介面會以**最大**顯示。

| 槓桿 | 最高可投入金額 |
| ---- | -------------- |
| 5x   | $1,000         |
| 10x  | $500           |
| 25x  | $200           |
| 50x  | $100           |
| 100x | $50            |

最低金額為 $1。

## 槓桿移動虧損線

用更少的錢買同樣大小的部位，代表風險更高。槓桿越高，歸零價越靠近目前價格，約 50x 起甚至會越過目前價格，所以只要出一點差錯就會全部虧光。

以下是 Bitcoin 價格 $100,000 時，五個為期三天、部位規模皆為 $5,000 的 Bitcoin 多單：

| 槓桿 | 投入金額 | 歸零價   | 損益兩平價 | 最高賠付 |
| ---- | -------- | -------- | ---------- | -------- |
| 5x   | $1,000   | $83,738  | $100,486   | $1,568   |
| 10x  | $500     | $91,402  | $100,542   | $1,017   |
| 25x  | $200     | $97,388  | $101,283   | $648     |
| 50x  | $100     | $100,466 | $102,476   | $474     |
| 100x | $50      | $102,936 | $103,965   | $343     |

以上為範例數字，你的實際數字會顯示在圖表上。

- **低槓桿**是對價格的小額、穩健押注。很少全部虧光，也很少賺到好幾倍。
- **高槓桿**在價格朝你的方向小幅變動時就能賺很多，但朝反方向小幅變動就會全部虧光。

**越過歸零價後，價格每多走 1%，賠付就增加你金額的「槓桿倍數」%**，直到上限為止。在 25x 時，每 1% 等於投入金額的 25%。市場平靜時，這些線會更靠近目前價格；市場波動大時則會離得更遠，因為賣方會把更大的價格變動計入報價。

## 沒有強平價

部位持有期間不會發生任何事。如果一筆 25x 多單在第一天反向走了 10%，第二天回升，第三天仍會全額賠付。同樣槓桿的永續合約在第一天就會被平倉出局。

## 如何選擇槓桿

問問自己：你認為結束時間的價格會在哪裡，而不是你想賺多少。

- 如果你認為價格會緩慢朝你的方向移動或維持不變，選擇低槓桿。
- 如果你認為價格會明確大幅變動，選擇高槓桿。

做決定之前，調整槓桿並觀察圖表上的色帶如何移動。
