# 永續合約與 Isometric 比較

永續合約和 Isometric 部位表達的是同一種看法：價格會漲，或價格會跌。兩者的差別在於過程中你可能遇到什麼。

## 並列比較

|              | 永續合約                         | Isometric                                |
| ------------ | -------------------------------- | ---------------------------------------- |
| **投入金額** | 保證金，可以追加或被扣除         | 一次性付款，即全部成本                   |
| **最大虧損** | 你的保證金，在某些平台上甚至更多 | 你支付的金額，絕不會更多                 |
| **強平**     | 有。價格越過強平價就會被平倉出局 | 無。不論中間發生什麼，部位都會持有到結算 |
| **資金費率** | 持倉期間每隔幾小時支付或收取     | 無                                       |
| **出場**     | 隨時                             | 僅在結算時                               |
| **獲利空間** | 無上限                           | 以圖表上顯示的 Max 為上限                |
| **期限**     | 無到期日                         | 12 小時至 7 天，拖曳結束線設定           |
| **交易對手** | 透過訂單簿與其他交易者成交       | 報價成交的賣方，你的賠付在開倉時就已鎖定 |
| **你收到的** | 保證金加減損益                   | 以 USDG 支付的賠付，或什麼都沒有         |

## 結算時的損益

兩者在價格每變動 1% 時的賠付相同，因為相同金額搭配相同槓桿就是相同的部位規模。永續合約從你的進場價開始計算價格變動。Isometric 部位則從歸零價開始計算，並在上限價停止。

## Isometric 更適合的情況

**你不會因為雜訊而被洗出場。** 25x 的永續合約遇到 4% 的插針就會被強平。25x 的 Isometric 部位則無視插針，只依整點的價格結算。如果你對當天的判斷正確，只是中間有一小時看錯，只有 Isometric 會讓你獲利。

**持有不需成本。** 永續合約部位若持有幾天、遇上資金費率偏高的時期，資金費率造成的虧損可能比價格變動還多。Isometric 部位沒有任何持續成本。

**簽署前就知道最壞情況。** 不會有欠款超過你支付金額的情況，不會有半夜三點的追繳保證金，也不會有連環強平。

**整筆規模同一個價格。** 賣方為全部金額報價。沒有需要逐檔吃單的訂單簿，也不會部分成交，交易會依你確認的報價開立，否則就不會開立。

## 永續合約更適合的情況

**你想提前出場。** 永續合約讓你隨時停利或停損。Isometric 部位做不到，第一天有獲利的部位到了第三天仍可能歸零結束。

**你想要無上限的獲利空間。** Isometric 部位達到 **Max**（最高賠付）後就不再增加獲利。永續合約則會一直增加。

**你想持續追蹤價格。** Isometric 部位只依單一整點的一個價格結算。永續合約的損益則隨時反映即時價格。

**你整天頻繁進出。** Isometric 部位的最短天期為 12 小時。

## 下跌後回升

第二天價格跌破強平價時，永續合約被平倉，錯過了之後的回升。以相同價格、相同槓桿開立的 Isometric 部位，在價格回升時仍然持有中，最終以獲利結算。

## 同樣的看法，不同的機制

如果你已經在交易永續合約，可以把 Isometric 部位想成拿掉保證金機制的同一筆方向性交易。你放棄了提前出場的能力和無上限的尾部獲利，換來固定成本、不會強平、沒有資金費率，以及只看結束時價格的結算方式。
