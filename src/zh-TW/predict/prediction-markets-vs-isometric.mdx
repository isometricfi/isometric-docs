# 預測市場與 Isometric 比較

上架式預測市場（例如 Polymarket）提供的是別人寫好的題目：Bitcoin 週五會高於 $105,000 嗎？你只能從列表上的價格和日期中挑選。在 Isometric，題目由你自己來寫。

## 並列比較

|                | 上架式預測市場         | Isometric                         |
| -------------- | ---------------------- | --------------------------------- |
| **價格**       | 少數幾個預設價位       | 賣方願意報價的任何價格            |
| **結束時間**   | 預設日期               | 12 小時至 7 天內的整點天期        |
| **成交**       | 取決於訂單簿深度       | 賣方一次為你的全部金額報價        |
| **賠付**       | 每份額固定             | 下單時即已固定                    |
| **最大虧損**   | 你支付的金額           | 你支付的金額                      |
| **出場**       | 通常可隨時賣出你的份額 | 持有至結束時間                    |
| **由什麼決定** | 該市場自己的判定規則   | 結束時間的一個鏈上 Chainlink 價格 |

## Isometric 更適合的情況

- **你對自己設定的價位有看法。** 週二 18:00 前 BTC 高於 $103,500，即使沒有人上架這道題目，你也可以下這筆預測。
- **你希望整筆金額同一個價格。** 沒有需要逐檔吃單的訂單簿。
- **你想要明確的結果。** 由一個鏈上價格結算，沒有爭議或投票。

## 上架式市場更適合的情況

- **你想提前出場。** 通常可以在結束前賣出你的份額。Isometric 預測會持有到結束時間。
- **你想押注價格以外的事情。** Isometric 只預測市場價格。

預測之前，請閱讀[了解風險](./risks.mdx)。
