# 名詞解釋

| 術語                      | 說明                                                                                                 |
| ------------------------- | ---------------------------------------------------------------------------------------------------- |
| 金額（Amount）            | 你在**投入金額**中輸入的數字，以 USDG 計算。與槓桿一起決定部位規模，也是你支付的全部費用（含手續費） |
| Arbitrum                  | Isometric 運行所在的 Ethereum 第二層網路。Arbitrum One 是主網，Arbitrum Sepolia 是測試網             |
| 測試版（Beta）            | Isometric 目前在 Arbitrum One 上的版本，合約尚未經過審計，部位規模有上限                             |
| 損益兩平價（Breakeven）   | 部位賠付剛好等於成本時的結束價。圖表上的綠色價格                                                     |
| Chainlink                 | 預言機網路，其價格來源是每筆報價的起點，並在結束時間決定每個部位的結果                               |
| 領取（Claim）             | 取回轉入你錢包時失敗的賠付。你可以將其發送到任何地址                                                 |
| 擔保品（Collateral）      | 部位開立時賣方存入的資金：**最高賠付**減去交易者的權利金                                             |
| 合約數量（Contracts）     | 以該市場資產為單位的部位大小                                                                         |
| 示範模式（Demo mode）     | 以模擬資金運行的 App。不需錢包、Gas 或區塊鏈                                                         |
| 方向（Direction）         | 做多或做空                                                                                           |
| 結束時間（End time）      | 交易或預測結束的日期與整點，顯示為**結束**。由該時間的一個 Chainlink 價格決定結果                    |
| 結束中（Ending）          | 已過結束時間、但結束價尚未記錄的部位                                                                 |
| Keeper                    | 在結束時間後記錄結束價並支付部位賠付的自動化程式。任何人都可以做同樣的事                             |
| 槓桿（Leverage）          | 部位規模除以你的金額，5x 至 100x。決定部位規模和虧損線的位置。永遠不會產生強平價                     |
| 做多（Long）              | 結束價高於歸零價時賠付的部位                                                                         |
| 虧損（Lost）              | 已結束且無賠付的部位                                                                                 |
| 最高賠付（Max payout）    | 部位可賠付的最高金額，在開倉時固定。圖表上的 **Max** 標籤以獲利金額顯示                              |
| 已賠付（Paid）            | 已結束且賠付已轉入你錢包的部位                                                                       |
| 賠付（Payout）            | 價格結束於目標價格或越過時，預測可獲得的金額，顯示為**若預測正確**                                   |
| 部位規模（Position size） | 你的金額乘以槓桿，即你的曝險。目前每筆交易上限為 5,000 USDG                                          |
| 預測（Prediction）        | 押注價格在結束時間高於或低於某個目標價格                                                             |
| 權利金（Premium）         | 交易者為部位支付給賣方的金額：投入金額扣除交易手續費                                                 |
| 報價（Quote）             | 賣方為一筆交易簽署的價格。由最優報價成交                                                             |
| 已退款（Refunded）        | 結束時間後 14 天內沒有結束價的部位。雙方都已取回資金（扣除手續費）                                   |
| 做空（Short）             | 結束價低於歸零價時賠付的部位                                                                         |
| 履約價（Strike）          | 歸零價在選擇權中的術語                                                                               |
| 目標價格（Target）        | 預測的結束價必須達到或越過才能全額賠付的價格                                                         |
| 兌換（Swap）              | 在 Arbitrum 上或跨網路將一種代幣換成另一種。用 USDC 和 USDT 支付交易時，會兌換為 USDG                |
| 天期（Term）              | 部位持有的時間長度。12 小時至 7 天                                                                   |
| USDG                      | Global Dollar，美元穩定幣。部位以其結算、賠付以其支付，賣方也以其存入資金                            |
| 獲利（Won）               | 已結束且有賠付、但轉帳失敗的部位。請領取                                                             |
| 歸零價（Worthless price） | 結束價等於或越過此價時部位無賠付。圖表上紅色的 **Lose** 線                                           |
| 賣方（Writer）            | 透過報價承接預測和交易另一方的任何人                                                                 |
