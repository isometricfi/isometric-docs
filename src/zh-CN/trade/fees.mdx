# 手续费

一个仓位只需在开仓时支付一次。你投入的金额就是你支付的全部费用，已含手续费。

## 交易手续费

手续费为 **$0.50 加上仓位规模的 0.04%**，且不超过你投入金额的 5%。它从投入金额中扣除，绝不额外加收。

## 你永远不用付的费用

| 在永续合约上     | 在 Isometric 上 |
| ---------------- | --------------- |
| 每小时的资金费率 | 无              |
| 平仓手续费       | 无。没有平仓    |
| 强平罚金         | 无。没有强平    |
| 赔付的提现手续费 | 无              |
| 从你的利润中抽成 | 无              |

## 网络费用

用 USDG 开仓只需在 Arbitrum 上发送一笔交易，用你钱包中的 ETH 支付。任何授权要么是免费签名，要么与交易一起发送。

结算由 Isometric 的 Keeper 发起，它自行承担网络费用，赔付直接进入钱包。只有当你需要自己[领取](./payouts-and-claims.mdx)赔付时，才需要在结算后支付网络费用。

## 兑换成本

Isometric 不对兑换收取任何费用，包括你用 USDC 或 USDT 支付交易时。汇率来自负责兑换路由的第三方。如果你的钱包不支持批量交易，用 USDC 或 USDT 支付还需承担授权和兑换的网络费用。参见[支付与兑换](./pay-and-swap.mdx)。

## 手续费会变吗

手续费可以在合约代码规定的范围内调整。调整只适用于之后开立的仓位，绝不影响已开立的仓位。
