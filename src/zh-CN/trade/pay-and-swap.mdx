# 支付与兑换

每笔预测和交易都以 **USDG** 结算，每笔赔付都以 **USDG** 支付。你不需要持有 USDG 就能开始，还可以从其他网络转入资金，再转出去。

## 用 USDC 或 USDT 支付

在下单面板上，点击**投入金额**旁边的代币，选择 Arbitrum One 上的 USDG、USDC 或 USDT。在你继续之前，弹窗会显示兑换价格。

你的投入金额始终以 USDG 计算。如果你用 USDC 或 USDT 支付，应用会在开仓时恰好买入这么多 USDG，最大滑点为 0.5%。下单面板会预留约 1% 的余额用于兑换，所以你无法花光全部余额。

如何上链取决于你的钱包：

- **如果你的钱包支持批量交易，** 兑换和交易会一起执行，要么都成功，要么都不发生。
- **如果不支持，** 钱包会先发送代币授权（如需要），然后是兑换，最后是交易。如果兑换成功而交易随后失败，USDG 会留在你手中，你可以再次交易或把它兑换回去。

用 USDG 支付无需兑换。

## 兑换

打开账户菜单，选择**兑换（跨链）**。选择你支付和收到的代币，以及各自所在的网络。

| 兑换               | 执行方                  | 耗时               |
| ------------------ | ----------------------- | ------------------ |
| 在 Arbitrum One 内 | Velora，一个 DEX 聚合器 | 几秒钟             |
| 与其他网络之间     | Relay，一个跨链桥       | 以报价中的预估为准 |

你可以在 Arbitrum One 与 Ethereum、Base、Optimism、Polygon、BNB Chain、Avalanche、HyperEVM、Hyperliquid 和 Robinhood Chain 之间兑换。

### 转入资金

用其他网络上的代币支付，在 Arbitrum One 上收到 USDG、USDC 或 USDT。之后你就可以下单预测或交易。

### 转出资金

赔付以 Arbitrum One 上的 USDG 形式到达你的钱包。要转移它们，选择用 Arbitrum One 上的 USDG 支付，再选择你想收到的代币和网络。

### 确认之前

兑换会显示**最少收到**、**价格影响**、**最大滑点**、**路径**和**预计时间**。如果在你发送之前价格变动超出了最少收到的范围，应用会停止并请你查看新报价。

### 成本

Isometric 不对兑换收取任何费用。你看到的汇率来自负责兑换路由的第三方，你需要在发送资金的网络上支付网络费用。从 Hyperliquid 发起的兑换是签名，而不是发送一笔交易。

### 如果跨链兑换未能成交

在兑换弹窗中打开**兑换记录**来跟踪兑换。它会显示**处理中**、**完成**、**已退款**或**失败**。如果 Relay 无法完成兑换，它会在你发送资金的网络上退还你的存款。

<Warning>Velora 和 Relay 是第三方，并非由 Isometric 运营。参见[了解风险](./risks.mdx)。</Warning>
