# 预测市场与杠杆交易对比

价格预测市场提出的是一个“是或否”的问题：下周五比特币会高于 $103,000 吗？Isometric 交易乍看相似，因为都是由某个时间点的一个价格决定结果。区别在于赔付。预测市场为“越过一条线”付钱，Isometric 为价格“越过多远”付钱。

## 并列对比

|                  | 价格预测市场                         | Isometric                            |
| ---------------- | ------------------------------------ | ------------------------------------ |
| **你选择的是**   | 一个上架的问题：一条价格线和一个日期 | 方向、结束时间、投入金额和杠杆       |
| **赔付**         | 全有或全无：猜对时每份固定金额       | 每越过归零价 1% 就增加，直到最高赔付 |
| **险些命中**     | 没有赔付                             | 可以拿回部分支付金额                 |
| **最大亏损**     | 你支付的金额                         | 你支付的金额                         |
| **你支付的价格** | 由其他交易者决定，深度取决于订单簿   | 由卖方报价，一次覆盖全部规模         |
| **退出**         | 通常随时可以卖给其他交易者           | 仅在结算时                           |
| **日期**         | 别人上架的日期                       | 12 小时至 7 天的期限                 |
| **由什么决定**   | 该市场自己的结算规则                 | 结算整点的 Chainlink 价格            |

## 同一个观点，两种做法

比特币现价 $100,000，你认为三天后会更高。你有 $100。

- **预测市场。** 你在“3 天后高于 $103,000？”上买入“是”。假设“是”的价格为 30 美分，猜对时每份支付 $1。$100 大约能买 333 份。
- **Isometric。** 你开立[读懂图表](./reading-the-chart.mdx)中那个三天期、25x 的多单：归零价 $97,400，盈亏平衡价 $101,296，最高赔付 $323。

| 结算时比特币价格 | 预测市场赔付 | Isometric 赔付 |
| ---------------- | ------------ | -------------- |
| $99,000          | $0           | $41            |
| $102,000         | $0           | $118           |
| $105,000         | $333         | $195           |
| $107,000         | $333         | $246           |
| $112,000         | $333         | $323           |

对于刚好越过那条线的行情，预测市场赔得更多。Isometric 在险些命中时会退还一部分钱，并随着行情扩大持续增加赔付，直到上限。以上数据仅为示例：两边的实际价格都会随市场变动。

## Isometric 更适合的情况

- **你有方向判断，而不是一条具体的线。** 你不需要去找价格和日期都合适的上架问题。选择做多或做空和结束时间，图表会显示每个价格对应的赔付。
- **你希望按行情幅度获得赔付。** 大行情比小行情赔得更多。
- **你希望险些命中也算数。** 在 **Some back** 区间，你能拿回部分资金。
- **你希望整笔规模一个价格。** 卖方为全部金额报价，没有订单簿需要逐档吃单。

## 预测市场更适合的情况

- **你只对某一条线有判断。** 如果你只关心价格能否突破 $103,000，“是或否”份额恰好表达了这一点。
- **你想提前退出。** 你通常可以在结算前卖出份额。Isometric 仓位会持续到结算。
- **你想交易价格以外的东西。** Isometric 只交易市场价格。
