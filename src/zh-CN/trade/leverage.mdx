# 这里的杠杆是什么意思

在永续合约上，杠杆代表你借了多少钱，并且伴随一个会让你爆仓的价格。在 Isometric 上，没有借贷，也没有强平。杠杆只做两件事：决定你的仓位有多大，以及图表上 **Lose** 线的位置。

在下单面板的**杠杆**中选择：5x、10x、15x、20x、25x、30x、40x、50x、75x 或 100x。

## 杠杆决定仓位规模

你的仓位规模等于投入金额乘以杠杆，每笔交易上限为 **5,000 USDG**。杠杆越高，你最多能投入的金额越低，下单面板上显示为**最大**。

| 杠杆 | 最多可投入 |
| ---- | ---------- |
| 5x   | $1,000     |
| 10x  | $500       |
| 25x  | $200       |
| 50x  | $100       |
| 100x | $50        |

最低投入金额为 $1。

## 杠杆移动亏损线

用更少的钱买同样规模的仓位，意味着更高的风险。杠杆越高，归零价离当前价格越近，大约从 50x 起还会越过当前价格，因此只要稍有不利，你就会全部亏掉。

以下是比特币价格为 $100,000 时的五个三天期比特币多单，仓位规模均为 $5,000：

| 杠杆 | 投入金额 | 归零价   | 盈亏平衡价 | 最高赔付 |
| ---- | -------- | -------- | ---------- | -------- |
| 5x   | $1,000   | $83,738  | $100,486   | $1,568   |
| 10x  | $500     | $91,402  | $100,542   | $1,017   |
| 25x  | $200     | $97,388  | $101,283   | $648     |
| 50x  | $100     | $100,466 | $102,476   | $474     |
| 100x | $50      | $102,936 | $103,965   | $343     |

以上为示例数据，你的实际数据以图表为准。

- **低杠杆**是对价格的一笔稳妥的小额押注。它很少全部亏光，也很少获得数倍回报。
- **高杠杆**在价格朝你的方向小幅波动时就能赚很多，朝反方向小幅波动时就会全部亏光。

**价格每越过归零价 1%，赔付就增加投入金额的“杠杆倍数”个百分点**，直到最高赔付。在 25x 时，每 1% 相当于你投入金额的 25%。市场平静时，这些线离当前价格较近；市场波动大时，它们离得更远，因为卖方会把更大的波动计入报价。

## 没有强平价

持仓期间，你的仓位不会受到任何影响。如果一个 25x 多单在第一天逆向波动 10%，第二天回升，它在第三天仍然全额赔付。同样杠杆的永续合约在第一天就会被平仓。

## 如何选择杠杆

问问自己，你认为结束时间的价格会在哪里，而不是你想赚多少。

- 如果你认为价格会朝你的方向缓慢移动或保持不变，选择低杠杆。
- 如果你认为价格会出现明确的大幅波动，选择高杠杆。

在做决定前，调整杠杆，观察图表上的区间如何移动。
