# 读懂图表

图表就是下单面板。左侧是过去两天的价格。右侧，在标有**结束**的线之后，是一组区间，显示你的交易在每个可能的结束价格下的赔付。只有这条线上的价格才算数，中途的下跌不决定任何事。

## 区间

以做多为例，从上到下：

| 区间          | 含义                                                         |
| ------------- | ------------------------------------------------------------ |
| **Max**       | 达到或越过最上方价格后，赔付不再增长。标签显示你的最高盈利。 |
| 绿色          | 在中间价格和最上方价格之间，你拿回的比投入的多。             |
| **Some back** | 在最下方价格和中间价格之间，你能拿回部分投入。               |
| **Lose**      | 等于或低于最下方价格时，交易没有赔付。标签显示你的亏损。     |

做空的图表正好上下颠倒：**Max** 区间在最下方，**Lose** 在最上方。

右侧边缘的三个价格分别是**归零价**（红色）、**盈亏平衡价**（绿色）和**上限价**（**Max** 开始的位置）。在区间内任意位置悬停或点按，即可看到对应的结束价格及其确切赔付。

## 什么会移动区间

- **杠杆。** 杠杆越高，**Lose** 线离当前价格越近，较小的反向波动就会让你全部亏光。价格每越过归零价 1%，赔付也越多。参见[杠杆](./leverage.mdx)。
- **结束线。** 结束时间越晚，盈亏平衡价会稍微远一些，**Max** 区间也更远，因此最高赔付更高。
- **投入金额。** 投入金额越大，每档赔付按比例放大，价格位置保持不变。

## 完整示例

比特币现价 **$100,000**。你选择**做多**，投入 **$100**，杠杆 **25x**，并把结束线拖到 **3 天**。图表可能显示：

| 图表上的价格 | 数值                           |
| ------------ | ------------------------------ |
| 上限价       | $110,000，标签为 **Max +$223** |
| 盈亏平衡价   | $101,296                       |
| 归零价       | $97,400，标签为 **Lose $100**  |

每个结束价格的赔付：

| 结束时比特币价格 | 你收到 | 结果  |
| ---------------- | ------ | ----- |
| $97,400 或更低   | $0     | −$100 |
| $100,000         | $67    | −$33  |
| $101,296         | $100   | $0    |
| $104,000         | $169   | +$69  |
| $107,000         | $246   | +$146 |
| $110,000 及以上  | $323   | +$223 |

在 25x 时，价格每越过归零价 1%，价值约为你投入金额的 25%，这里约为 $25。超过 $110,000 后赔付不再增长：比特币涨到 $150,000 也同样赔付 $323。

以上为示例数据。你的实际数据取决于实时价格和卖方发来的报价。

## 报价跟随市场

区间会随价格变动而更新。每个报价在短时间内有效，应用会在你签名前刷新报价。你的交易要么完全按你确认的报价开立，要么不开立。失败的交易只花费网络费用。
