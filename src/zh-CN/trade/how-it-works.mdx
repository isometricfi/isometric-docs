# 运作原理

每个 Isometric 仓位都是一个期权价差。

- **做多是看涨价差。** 价格涨过你的归零价后开始赔付，直到上限。
- **做空是看跌价差。** 价格跌破你的归零价后开始赔付，直到下限。
- **你买入价差，卖方卖出价差。** 卖方竞相为你的交易报价，最优报价成交。
- **完全足额抵押。** 交易开立时，你的权利金和卖方的存款就足以覆盖你的全部**最高赔付**。
- **在结束时间一次性结算。** 由一个 Chainlink 价格决定赔付，以 USDG 支付。不能提前行权，也不能提前平仓。

## 用期权术语解读图表

| 图表上          | 期权术语                             |
| --------------- | ------------------------------------ |
| **Lose** 线     | 行权价                               |
| **Max** 线      | 上限价，做空时为下限价               |
| 最高赔付        | 价差的全部价值，即行权价与上限价之间 |
| 投入金额        | 权利金加交易手续费                   |
| 投入金额 × 杠杆 | 名义价值                             |
| **结束**        | 到期时间                             |

杠杆等于名义价值除以你支付的金额。它决定价差的规模，而不是保证金要求，所以没有什么可以被强平。
