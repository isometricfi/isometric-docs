# 永续合约与 Isometric 对比

永续合约和 Isometric 仓位表达的是同一种观点：价格会涨，或者会跌。区别在于过程中可能发生在你身上的事。

## 并列对比

|                | 永续合约                           | Isometric                                |
| -------------- | ---------------------------------- | ---------------------------------------- |
| **你投入的是** | 保证金，可以追加或取出             | 一次性付款，即全部成本                   |
| **最大亏损**   | 你的保证金，在某些平台上还可能更多 | 你支付的金额，绝不会更多                 |
| **强平**       | 有。价格越过强平价就会被平仓       | 没有。无论中途发生什么，仓位都持续到结算 |
| **资金费率**   | 持仓期间每隔几小时支付或收取       | 没有                                     |
| **退出**       | 随时                               | 仅在结算时                               |
| **上行空间**   | 无上限                             | 以图表上显示的 Max 为上限                |
| **持续时间**   | 无固定期限                         | 12 小时至 7 天，通过拖动结束线设定       |
| **对手方**     | 通过订单簿成交的其他交易者         | 报价成交的卖方，你的赔付预先锁定         |
| **你收到的是** | 保证金加减盈亏                     | 以 USDG 支付的赔付，或者什么都没有       |

## 结算时的盈亏

价格每变动 1%，两者的盈亏相同，因为同样的投入金额配同样的杠杆就是同样的仓位规模。永续合约从你的开仓价开始计算这一变动；Isometric 仓位从归零价开始计算，并在上限处停止。

## Isometric 更好的地方

**你不会被噪音止损出局。** 一根 4% 的插针就能让 25x 永续合约被强平。25x 的 Isometric 仓位会无视这根插针，按整点的价格结算。如果你对当天的判断是对的，只是中途有一个小时看错了，只有 Isometric 会给你赔付。

**持仓没有成本。** 一个永续合约仓位在资金费率很高的几天里持有，亏在资金费率上的钱可能比亏在价格上的还多。Isometric 仓位没有任何持续成本。

**签名之前就知道最坏结果。** 不存在你欠下超过支付金额的情况，没有凌晨三点的追加保证金通知，也没有连环爆仓。

**整笔规模一个价格。** 卖方为全部金额报价。没有订单簿需要逐档吃单，也没有部分成交，交易要么按你确认的报价开立，要么根本不开立。

## 永续合约更好的地方

**你想提前退出。** 永续合约让你随时止盈或止损。Isometric 仓位不行，第一天盈利的仓位到第三天仍可能到期归零。

**你想要无上限的收益。** Isometric 仓位在达到 **Max** 后不再增加收益。永续合约会一直涨下去。

**你想连续跟踪价格。** Isometric 仓位按某一个整点的一个价格结算。永续合约的盈亏随时反映实时价格。

**你整天频繁进出。** Isometric 仓位的最短期限为 12 小时。

## 下跌后反弹

价格在第二天跌穿永续合约的强平线，永续合约被平仓，错过了随后的反弹。在相同价格、以相同杠杆开立的 Isometric 仓位在反弹到来时仍在持仓中，并最终盈利结算。

## 同样的观点，不同的机制

如果你已经在交易永续合约，可以把 Isometric 仓位看成去掉了保证金引擎的同一笔方向性交易。你放弃了提前离场的能力和无上限的尾部收益，换来的是固定成本、不会被强平、没有资金费率，以及只关心结束时价格的结算方式。
