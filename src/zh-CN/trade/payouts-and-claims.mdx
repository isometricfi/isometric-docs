# 赔付与领取

每笔赔付，无论做多还是做空，都以 **USDG** 支付，即使你当初用 USDC 或 USDT 付款。要把它换成其他代币或转到其他网络，请使用[兑换](./pay-and-swap.mdx)。

## 仓位何时赔付

赔付会自动完成。它在记录结束价格的同一笔交易中转入你的钱包，通常在结束时间后一两分钟内。之后仓位显示为**已赔付**。

## 什么时候需要领取

如果转入你钱包的转账失败，例如你的钱包被禁止接收 USDG，该仓位会改为显示**获胜**。你没有任何损失。赔付会留在合约中等待你，永不过期。

打开**投资组合**，选择该仓位，点击**领取**。将其发送到**我的钱包**或**其他地址**。

<Warning>
  全部赔付将发送至你输入的地址且无法退回。请逐字核对，并确保该地址可以在 Arbitrum One 上接收 USDG。
</Warning>

## 仓位状态

| 状态   | 含义                                                             |
| ------ | ---------------------------------------------------------------- |
| 持仓中 | 结束时间尚未到来                                                 |
| 结束中 | 结束时间已过，结束价格正在等待记录                               |
| 已赔付 | 已结束并赔付至你的钱包                                           |
| 获胜   | 已结束并产生赔付，但转账失败。去领取它                           |
| 亏损   | 结束价落在区间之外，因此没有赔付                                 |
| 已退款 | 结束时间后 14 天内没有结束价格，你支付的金额已退还（扣除手续费） |

## 投资组合显示的内容

| 数据                 | 含义                                           |
| -------------------- | ---------------------------------------------- |
| 持仓若立即结束的价值 | 按当前价格计算，你的持仓可获得的赔付。仅供参考 |
| 持仓最高赔付         | 你的持仓最多可获得的赔付                       |
| 可领取               | 等待你领取的赔付                               |
| 胜率                 | 已结束仓位中赔付高于成本的比例                 |
| 总投入（含手续费）   | 你为仓位支付的全部金额                         |
| 总赔付               | 你已收到的全部赔付                             |
| 已实现盈亏           | 已结束仓位的总赔付减去总投入                   |

每一行都链接到对应的交易，因此每一步都可以在链上核查。
