# 预测如何赔付

预测是押注某个价格在你的结束时间高于或低于你的目标价。你只需支付一次，赔付金额显示为 **If you're right**（若预测正确），在下单时即已固定。

## 赔付

你的权利金（扣除手续费后支付的金额）承担一部分赔付。预测开立时，卖方存入其余部分，因此合约中已经备足了它最多可能付给你的金额。

单笔预测最多赔付 1,000 USDG，且不超过投入金额的 10 倍。选定目标价并不保证一定有报价。

## 为什么有些目标价赔得更多

赔付反映了卖方认为你的目标价有多大可能达到。如果投入 $100 时 **If you're right** 显示 $400，说明卖方估计概率约为 25%。目标价离当前价格越远，或结束时间越近，达到的可能性越小，因此赔付越高。

## 由什么决定结果

合约使用**你结束时间当时或之前发布的最后一个 Chainlink 价格**。如果该读数超出喂价允许的时效、为零或为负，则改由结束时间之后的第一个读数决定结果，前提是该读数为正。

| 结束时的价格         | 你获得     |
| -------------------- | ---------- |
| 达到或越过你的目标价 | 全额赔付   |
| 距目标价不足 0.1%    | 按比例赔付 |
| 距目标价 0.1% 或以上 | 无赔付     |

例如，**BTC 高于 $100,000** 在 $100,000 或以上时全额赔付，在 $99,950 时赔付一半，在 $99,900 或以下时没有赔付。

## 收到赔付

赔付以 USDG 支付。Isometric 的 Keeper 会在每笔预测的结束时间后不久完成结算，赔付在同一笔交易中直接进入你的钱包，通常在一两分钟内。你无需点击任何按钮。之后预测会显示**赢得**及金额，或**无赔付**。

如果转入你钱包的转账失败，赔付会留在合约中等待你，永不过期。在**投资组合**中打开该预测，点击**领取**，即可发送到你的钱包或其他地址。

如果结束时间后 14 天内没有发布 Chainlink 价格，预测将被退款（扣除手续费）。

## 无法提前退出

预测不能平仓、调整规模或转让，会一直持续到结束时间。在此之前，它会显示当前是否**符合预期**，或价格还需要变动多少。
