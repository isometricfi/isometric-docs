# 预测市场与 Isometric 对比

上架式预测市场（例如 Polymarket）提供的是别人写好的问题：周五比特币会高于 $105,000 吗？你只能从列表中的价格和日期里挑选。在 Isometric 上，问题由你自己来写。

## 并列对比

|                | 上架式预测市场       | Isometric                             |
| -------------- | -------------------- | ------------------------------------- |
| **价格**       | 少数几个预设价位     | 卖方报价的任意价格                    |
| **结束时间**   | 预设日期             | 12 小时至 7 天的整点期限              |
| **成交**       | 深度取决于订单簿     | 卖方一次为你的全部金额报价            |
| **赔付**       | 每份固定             | 下单时即已固定                        |
| **最大亏损**   | 你支付的金额         | 你支付的金额                          |
| **退出**       | 通常随时可以卖出份额 | 持有至结束时间                        |
| **由什么决定** | 该市场自己的结算规则 | 结束时间的一个 Chainlink 价格，在链上 |

## Isometric 更适合的情况

- **你对自己设定的价位有判断。** 周二 18:00 前 BTC 高于 $103,500，即使没有人上架这个问题，你也可以下单这笔预测。
- **你希望全部金额一个价格。** 没有订单簿需要逐档吃单。
- **你想要明确的结果。** 由一个链上价格结算，没有争议或投票。

## 上架式市场更适合的情况

- **你想提前退出。** 你通常可以在结束前卖出份额。Isometric 预测会持续到结束时间。
- **你想押注价格以外的东西。** Isometric 只预测市场价格。

预测之前，请阅读[了解风险](./risks.mdx)。
