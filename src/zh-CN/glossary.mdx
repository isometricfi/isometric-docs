# 术语表

| 术语                      | 含义                                                                                                 |
| ------------------------- | ---------------------------------------------------------------------------------------------------- |
| 投入金额（Amount）        | 你在**投入金额**中输入的数额，以 USDG 计。它与杠杆一起决定仓位规模，也是你支付的全部金额（含手续费） |
| Arbitrum                  | Isometric 所在的以太坊二层网络。Arbitrum One 是主网，Arbitrum Sepolia 是测试网                       |
| 测试版（Beta）            | Isometric 当前在 Arbitrum One 上的发布阶段，合约未经审计，仓位规模设有上限                           |
| 盈亏平衡价（Breakeven）   | 仓位赔付恰好等于其成本时的结束价格。图表上的绿色价格                                                 |
| Chainlink                 | 预言机网络。它的喂价是每个报价的起点，也在结束时间决定每个仓位的结果                                 |
| 领取（Claim）             | 当赔付转入你钱包失败时，由你手动取回赔付。你可以把它发送到任意地址                                   |
| 抵押品（Collateral）      | 仓位开立时卖方存入的资金：**最高赔付**减去交易者的权利金                                             |
| 合约数量（Contracts）     | 以该市场资产为单位计算的仓位大小                                                                     |
| 演示模式（Demo mode）     | 使用模拟资金运行的应用。无需钱包、Gas 或上链                                                         |
| 方向（Direction）         | 做多或做空                                                                                           |
| 结束时间（End time）      | 交易或预测结束的日期和整点，显示为**结束**。由该时刻的一个 Chainlink 价格决定结果                    |
| 结束中（Ending）          | 已过结束时间、但结束价格尚未记录的仓位                                                               |
| Keeper                    | 在结束时间之后记录结束价格并完成仓位赔付的自动程序。任何人都可以做同样的事                           |
| 杠杆（Leverage）          | 仓位规模除以投入金额，5x 至 100x。它决定仓位规模和亏损线的位置，从不产生强平价                       |
| 做多（Long）              | 结束价格高于归零价时获得赔付的仓位                                                                   |
| 亏损（Lost）              | 已结束且没有任何赔付的仓位                                                                           |
| 最高赔付（Max payout）    | 仓位可能获得的最高赔付，开仓时即已固定。图表上的 **Max** 标签以盈利形式显示它                        |
| 已赔付（Paid）            | 已结束且赔付已到达你钱包的仓位                                                                       |
| 赔付（Payout）            | 当价格结束时达到或越过目标价时，预测支付的金额，显示为 **If you're right**（若预测正确）             |
| 仓位规模（Position size） | 投入金额乘以杠杆，即你的风险敞口。目前每笔交易上限为 5,000 USDG                                      |
| 预测（Prediction）        | 押注某个价格在结束时间高于或低于目标价                                                               |
| 权利金（Premium）         | 交易者为仓位支付给卖方的金额：投入金额减去交易手续费                                                 |
| 报价（Quote）             | 卖方为一笔交易签名给出的价格。最优报价成交                                                           |
| 已退款（Refunded）        | 结束时间后 14 天内没有结束价格的仓位。双方都拿回了各自的资金（扣除手续费）                           |
| 做空（Short）             | 结束价格低于归零价时获得赔付的仓位                                                                   |
| 行权价（Strike）          | 归零价在期权中的术语                                                                                 |
| 目标价（Target）          | 预测要获得全额赔付，价格结束时必须达到或越过的价格                                                   |
| 兑换（Swap）              | 在 Arbitrum 上或跨网络把一种代币换成另一种。USDC 和 USDT 用于支付交易时会兑换为 USDG                 |
| 期限（Term）              | 仓位持续的时长，12 小时至 7 天                                                                       |
| USDG                      | Global Dollar，一种美元稳定币。仓位以它结算，赔付以它支付，卖方也以它存入资金                        |
| 获胜（Won）               | 已结束且有赔付、但转账失败的仓位。去领取它                                                           |
| 归零价（Worthless price） | 结束价格达到或越过该价时，仓位没有任何赔付。图表上红色的 **Lose** 线                                 |
| 卖方（Writer）            | 通过报价成为预测和交易对手方的任何人                                                                 |
